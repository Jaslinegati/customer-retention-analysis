# Data

## Source
Olist Brazilian E-Commerce Public Dataset  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Setup
1. Download the dataset from Kaggle (requires free account)
2. Extract all CSVs into `data/raw/`

## Files expected in `data/raw/`
- olist_customers_dataset.csv
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_products_dataset.csv
- product_category_name_translation.csv

Raw data files are not committed to this repo.
Processed data (generated by notebooks) lives in `data/processed/`.
